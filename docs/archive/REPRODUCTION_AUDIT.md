## 论文与官方代码：当前 Hopper 的核心设置

下表“官方代码”指固定提交的默认值，未为匹配论文偷偷改参数。

| 核对项 | 论文 | 官方代码 | 结论 |
|---|---|---|---|
| token 顺序 | RTG、状态、动作 | 相同 | 一致 |
| 因果注意力 | 只读取当前及之前 token | 相同 | 一致 |
| 动作预测位置 | 状态 token 输出预测当前动作 | 相同 | 一致 |
| 连续动作训练 | 动作 MSE | mask 后计算动作 MSE | 一致 |
| 状态/RTG 辅助损失 | 主要 Gym 实验不要求 | 预测头存在，但没有加入训练损失 | 一致 |
| RTG | 当前步至结束的奖励和 | discount_cumsum(gamma=1) | 一致 |
| Transformer 层数 | 3 | 3 | 一致 |
| 注意力头 | 1 | 1 | 一致 |
| 隐藏维度 | 128 | 128 | 一致 |
| Hopper 上下文 K | 20 | 20 | 一致 |
| batch size | 64 | 64 | 一致 |
| 激活函数 | ReLU | relu | 一致 |
| dropout | 0.1 | 0.1 | 一致 |
| 优化器 | AdamW | AdamW | 一致 |
| 基础学习率 | 1e-4 | 1e-4 | 一致 |
| 权重衰减 | 1e-4 | 1e-4 | 一致 |
| 梯度裁剪 | 0.25 | 0.25（seq_trainer.py） | 一致 |
| 总参数更新次数 | 1e5 | 10 × 10000 = 1e5 | 一致 |
| 线性学习率预热 | 表 9 写 1e5 步 | 默认 warmup_steps=10000，即 1e4 步 | **明确差异，尚未判定哪一项对应论文实际运行** |
| Hopper 目标 RTG | 3600 | [3600, 1800] | 包含论文目标，另有额外评估 |
| 分数呈现 | D4RL 专家归一化评分 | 输出原始回报及回合长度 | 不能直接把原始回报与论文表格数值比较 |
| 随机种子 | 跨 3 个种子汇总 | 脚本没有 seed 参数或完整显式设种子逻辑 | 默认运行不能自动得到论文多种子结果 |

算法细节还有一点值得记录：论文架构段描述模态投影后归一化，官方 Gym 实现在堆叠 token 后使用一个共享的 `embed_ln`。
本次保留官方实现；不能仅依据文字简述自行重写成三个独立归一化层。

## 本地 Hopper 数据与已有结果

当前 `hopper-medium-v2.pkl` 的只读统计：2186 条轨迹，999906 个时间步，观测维度 11，动作维度 3；
平均原始轨迹回报约 1422.06，最小约 315.87，最大约 3222.36。
这些统计证明文件可读取、维度符合 Hopper，不证明数据来源和官方数据完全一致。
原始下载转换脚本只在终止或超时处写入完整轨迹，不单独写出循环末尾剩余片段；
总步数不足一百万需要结合原始 HDF5 的终止和超时标记核查，不能直接判定文件损坏。

此前运行使用现代依赖与 Hopper-v4，结果保留在原路径，应标为适配实验。
它们不能因本次恢复源码，就重新归类为旧环境下的官方基线结果。
